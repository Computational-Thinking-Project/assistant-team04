# Data Directory

Contains data sources used by the Smart Virtual Assistant.

## offices.csv

- **Description:** Directory of university offices, rooms, and opening hours.
- **Data source:** [HCMUS Office Directory](https://stsv.hcmus.edu.vn/danh-ba), [HCMUS Counseling Service](https://stsv.hcmus.edu.vn/ho-tro-tham-van-tam-ly)
- **Owner / Maintainer:** @nhatquynh1107
- **Update frequency:** As needed (when official information changes).
- **Verification status:** Some office locations and opening hours are demo or unverified data. The source does not verify every record.
